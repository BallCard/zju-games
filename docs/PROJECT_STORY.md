# Project Story

ZJU Games is a campus-themed lightweight game monorepo. The archived development branch focused on a cat-merging web game, including game configuration, Phaser scene behavior, React integration, and a final set of twelve cat levels.

The last local work expanded the game and replaced temporary art with the final cat images and animation strips. The repository is archived because active product development stopped after this asset and interaction pass.

## Key archive choices

- Preserve final cat images and generated animation strips because they are unique visual assets used by the game.
- Preserve the animation source frames for levels 10-12 because they explain how the strips were assembled.
- Exclude `node_modules/`, Turbo/Vite caches, build output, and temporary checkpoint ZIPs.
- Keep the existing complete Git bundle at `archive/zjugames-backup-20260319-011026.bundle` as a pre-art baseline recovery point.
